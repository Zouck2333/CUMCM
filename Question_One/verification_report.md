# 优化版结果核对报告

## 1. 核对结论

修订后的优化版已在当前计算机上完成实际运行验证。基础 LP、基础 MILP 和 45 个灵敏度情景均成功求解，基础 MILP 与 `Question_One` 原版结果逐时段完全一致。

## 2. 基础模型保护

批量灵敏度分析固定使用：

```text
method = milp
objective_mode = cost
```

灵敏度情景只改变显式参数，不删除或放松以下基础硬约束：

- 时段电力平衡；
- SOC 状态递推；
- SOC 上下限；
- 充放电功率上限；
- 初始和终端 SOC；
- 弃光量上下限；
- MILP 充放电互斥。

字典序目标仍可通过命令行显式选择，但不参与基础结果和灵敏度分析。

## 6. 运行环境修复

程序重新支持数据处理环境与求解器环境分离：

- 主 Python 负责 pandas、openpyxl 和输出；
- 求解器 Python 负责 SciPy/HiGHS；
- 可通过 `--solver-python` 显式指定求解环境；
- 三个 PowerShell 脚本会自动寻找可用主 Python；
- Python 失败时，脚本会正确返回非零退出码。

## 7. 最终判断

当前版本已经实现可复现的批量灵敏度分析，且基础模型回归结果与原版完全一致。新增功能没有改变基础 LP/MILP 的电力平衡、储能递推、容量、功率、弃光和互斥约束。
