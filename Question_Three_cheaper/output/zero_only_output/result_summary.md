# 仅 0:00 预报策略结果摘要

## 1. 策略口径

- 每个自然日只在 0:00 使用附件 3 的 0:00 光伏预报。
- 全天只求解一次 MILP，得到完整的 \(G^0,C^0,D^0\)。
- 6:00、12:00、18:00 不重新优化，全天执行 0:00 计划。
- 日末 SOC 不强制等于日初 SOC，只保留容量边界和跨日连续性。
- 实际结算使用附件 2 的实际负载和实际光伏，紧急购电按实时电价的 5 倍计费。
