# 运行环境与迁移说明

全部业务代码、输入附件、模板及正式结果包含在本目录中。运行时解释器和第三方库使用机器上已有安装。

| 用途 | 本次使用的环境 |
|---|---|
| MILP求解和滚动调参 | Python 3.14.2、NumPy 2.4.2、SciPy 1.17.1 |
| Excel只读提取和独立核验 | Python 3.12.14、NumPy 2.3.5、openpyxl 3.1.5 |
| Excel生成 | Node.js 24.19.0、`@oai/artifact-tool` 2.8.59 |
| 运行入口 | Windows PowerShell；脚本以UTF-8 BOM保存 |

Python依赖范围列于 `requirements.txt`。其他电脑可以用一个安装了所有Python依赖的环境同时完成求解与核验：

```powershell
python -m pip install -r .\requirements.txt
powershell -ExecutionPolicy Bypass -File .\run_question_two.ps1 -SolverPython "C:\path\python.exe" -ExcelPython "C:\path\python.exe" -NodeExecutable "C:\path\node.exe"
```

上面的路径是示例，需要替换为实际安装位置。数值库和MILP求解器版本变化可能造成最优解之间的细微差异，应重新执行完整核验。

默认入口从PATH寻找求解Python，从当前用户的 `.cache/codex-runtimes/codex-primary-runtime/dependencies` 寻找Excel核验Python和Node。也可以通过三个参数显式指定解释器。

`@oai/artifact-tool` 是本机Codex已提供的工作簿库，不包含在普通Python依赖中。入口发现包内没有 `node_modules` 时，会将其联接到本机Codex的Node依赖目录。其他电脑需要已有可用的同类Codex依赖，或在包内提供可解析的 `@oai/artifact-tool` 安装。此文件包未复制运行时或第三方依赖，也不承诺无依赖离线安装。

32天试运行只需要Python，可用于核对输入提取、1月预热和2月1日首次选参。查看已生成的 `output/result2.xlsx` 不需要上述计算环境。
