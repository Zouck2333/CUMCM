# 运行环境与校验说明

本次数值回算使用 Windows、Python 3.14.2、NumPy 2.4.2、SciPy 1.17.1（HiGHS）、Matplotlib 3.10.8。输入工作簿通过 openpyxl 只读加载。

电子表格由 Codex 捆绑依赖版本 26.909.12148 中的 Node.js 与 `@oai/artifact-tool` 生成。两次最终工作簿导出进程均正常结束，随后用 openpyxl 对全部数值独立复核。预览使用同一运行时在隔离进程中生成：该 Windows 原生渲染进程在完成全部 PNG 写入并输出完成标记后，以 3221226505 退出。因此预览程序记录了非正常退出状态，并单独验证每张 PNG 的全部 CRC、压缩数据和结束块；七张工作表图片及费用对照图还经过视觉检查。详情见 `output/render_verification.json`。

旧预测、负荷改进、自适应电价、终端价值四个实验均保留全年结果与各自的独立核验报告。两次中途退出的候选属于数值精度修正前实验，已放入 `archive`；重跑后的完整结果放在 `experiments`。

正式方案沿用终端价值实验中全部已成功验证的轨迹。原生成代码指纹已用保留的修正前求解器源码独立重建；当前求解器只对原版本本会拒绝的负流量增加补救步骤，不改变已成功轨迹。兼容元数据保留原指纹和完整记录哈希，运行入口再次核验后才允许复用。复现新配置或改动数据时，应选择新的输出目录。

```powershell
python -B -m Question_Four_optimized.code.verify_optimized
```
